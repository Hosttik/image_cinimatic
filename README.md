# BLOCKFRAME — Minecraft Machinima Generator (MVP)

Локальный сервис **промпт → AI-сценарист → 5 анимированных сцен → интерполяция → MP4**.
По умолчанию создаёт 20-секундный горизонтальный ролик 1280×720 / 30 FPS на тему Робинзона Крузо. Поддерживает 60 FPS. Интерфейс — на русском.

## Быстрый запуск

Нужны Python 3.11+ и установленный **FFmpeg** (`ffmpeg -version`).

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env      # Windows: copy .env.example .env
# Укажите OPENAI_API_KEY в .env для AI-режима. Для Demo ключ не нужен.
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте **http://127.0.0.1:8000**. Введите промпт и нажмите «Сгенерировать ролик». По завершении появится видеоплеер и кнопки скачивания MP4/JSON. Файлы каждого задания хранятся в `outputs/<job_id>/`.

### Режимы

- **Demo** — готовая пятисценная раскадровка и процедурно нарисованные анимированные пиксельные GIF. Позволяет проверить работу API, монтажа и UI без оплаты. Это **не** генерация через модель OpenAI; текст промпта не меняет demo-картинки.
- **AI** — запрос к Responses API на структурированную раскадровку, затем референс персонажа через `gpt-image-2.6-sunburst` и пять анимированных GIF по 16 кадров каждый через `POST /v1/images/edits`, сохраняя общий стиль/персонажа. **Требуются API-ключ и доступ к GIF preview.** Каждый запуск — платные API-запросы.

## Почему здесь GIF, а не 600 отдельных изображений

Image API поддерживает для `gpt-image-2.6-sunburst` GIF из **2–16 кадров** (`frame_count`) с настройкой задержки (`frame_duration_ms`). В MVP 5 сцен × 16 кадров × 250 мс = **20 секунд исходной анимации** (приблизительно 4 FPS). FFmpeg `minterpolate` создаёт промежуточные кадры на 30 или 60 FPS и H.264 MP4, в котором 600/1200 кадров. При сложных движениях оптическая интерполяция может создавать артефакты. Это **не** нативные 30/60 уникальных AI-кадров в секунду. Для настоящей непрерывной динамичной анимации потребуется видео-модель или 3D-анимационный движок.

## Архитектура

```
app/main.py      FastAPI + фоновая очередь из 1 worker + статусы задач
app/story.py     Responses API + JSON Schema + проверка сценария
app/images.py    Image API: PNG-референс + 5 GIF edits
app/render.py    FFmpeg interpolation, 5 клипов, MP4
app/demo.py      процедурный рендер без OpenAI
app/static/      UI на чистом HTML / CSS / JS
```

Этапы: `POST /api/jobs` → `GET /api/jobs/{id}` → `GET /api/jobs/{id}/video`, либо JSON по `/api/jobs/{id}/storyboard`. `/api/health` показывает состояние ключа без раскрытия его значения. Раскадровка и каждый промежуточный GIF остаются на диске для доработки.

## Ограничения и эксплуатация

- Это локальный MVP, **не публичный SaaS**. Нет аутентификации, квот пользователей, очереди в БД и очистки файлов. Запускайте с `127.0.0.1` и **одним** процессом `uvicorn`, не открывайте сервис в интернет без защиты.
- Не храните ключ в браузере; только в `.env` на сервере. `.env` и `outputs/` игнорируются Git.
- История заданий хранится в памяти процесса, поэтому после рестарта статус старых задач исчезает, хотя файлы остаются.
- Для GIF запрашивается `512x288` и 16 кадров; если превышены лимиты модели или GIF preview недоступен, API вернёт ошибку. Для продакшена нужны опции понижать число кадров/размер и контроль затрат.
- Ролик без звука. Успешность и качество реальной AI-генерации требуют прогона с вашим API-ключом; тестовый Demo этого не подтверждает.
- Сцены независимы по движению; один референс и «visual bible» уменьшают, но не устраняют визуальный дрейф между сценами.
